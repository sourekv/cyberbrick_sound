# Where things are

A short map of the repository. What each document says is in the table in `README.md` ("Documentation").

## Top level

| Directory | What is in it |
|---|---|
| `firmware/` | PlatformIO project of the module (ESP32-S3-Zero) |
| `web/` | The web app for the sound sets (`index.html`, open it in Chrome or Edge) |
| `tools/` | Python and C++ helpers: sound generation, PCB generators, analysis, tests |
| `assets/` | Sounds: recordings, the default sets, the test set |
| `hardware/` | The shield board (KiCad), the speaker box, the solder stand |
| `docs/` | Documentation, pictures, measurements, example configuration of the receiver |

## firmware/

| Path | What is in it |
|---|---|
| `platformio.ini` | The environments; the sound firmware is `engine_sets` (current), `engine_lab` and older ones are earlier stages |
| `src/<environment>/main.cpp` | One folder per environment: `engine_sets` (sets on the module, USB link), `engine_lab`, `engine_pulse`, `engine_real`, `engine_gears`, `engine`, and test programs (`test_tone`, `speaker_sweep`, `uart_probe`, `pulse_measure`) |
| `include/` | Shared headers: `config.h` (pins and constants), the engine models and sound players, `set_link.h` (the USB protocol), the generated sound data |
| `data/sets/` | The default sets, generated by `tools/make_default_sets.py` (not committed) |
| `partitions_sets.csv`, `version.py` | Flash partitions of `engine_sets`; the version number and build date |

## web/

| File | What it is |
|---|---|
| `index.html` | The whole app in one file |
| `number_names.js` | The spoken numbers 1..99 (generated by `tools/make_number_names.py`) |
| `demo_sets.js` | The default sets for the simulated module (generated, not committed) |

## assets/

| Path | What is in it |
|---|---|
| `samples/` | The original recordings and derived loops, with `LICENSE-SAMPLES.md` |
| `sets/` | The seven default sets (`01_truck` ... `07_v12`): sounds and `set.json` |
| `test_set/` | A test set for the web app (`09_test`) |

## hardware/

| Path | What is in it |
|---|---|
| `shield/` | KiCad project: schematic, board, DRC report |
| `shield/fab/` | Manufacturing files: Gerbers, assembly files for JLCPCB and PCBWay, BOMs, the interactive BOM (`shield_ibom.html`) |
| `speaker_box/` | The sealed speaker box: OpenSCAD source, STL files, the 3MF project, a Fusion 360 script |
| `solder_stand/` | The printed stand for soldering the sockets and J1 onto the shield |

## tools/

| Kind | Files |
|---|---|
| Sound | `engine_lab.py`, `simulate_engine.py`, `speaker_model.py`, `make_engine_*.py`, `make_*_loop.py`, `make_shift_sound.py`, `make_sample.py` |
| Sets and web app | `make_default_sets.py`, `make_user_sounds.py`, `make_test_set.py`, `make_number_names.py`, `make_voice_*`, `make_guide_images.py` |
| Shield | `make_shield_*.py`, `shield_*.py`, `place_shield.py`, `check_shield_netlist.py`, `check_shield_3d.py` (3D sizes, collisions, room under the Zero), `make_shield_3d_kicad.py` (the 3D page from KiCad), `render_pcb.py` |
| Measurement | `analyze_speaker_sweep.py` |
| Tests | `test_gearbox.cpp`, `test_gear_beep.cpp`, `render_engine_*.cpp` |

## docs/

| Path | What is in it |
|---|---|
| `project-overview.md`, `roadmap.md` | The whole project on one page; what is still open |
| `user-guide.md`, `guide/` | The guide to the web app with its pictures |
| `user-sounds.md` | How the sound sets and the USB protocol work inside |
| `shield-pcb.md`, `shield-*.md`, `shield-*.png`, `shield-schematic.pdf`, `shield-3d.html` (illustrative boxes with a parts list), `shield-3d-kicad.html` (the real board from KiCad) | The shield: design, orders, comparison, pictures |
| `wiring-current.*` | The wiring in use; `wiring-overview`, `wiring-stage2`, `wiring-test-tone` are earlier stages |
| `bringup.md`, `controls.md`, `start-stop-horn.md` | First power-up and measurements, the controls, the start, stop and horn sounds |
| `sound-research.md`, `speaker-measurement.md`, `measurements/` | Sound research; speaker tests and their data |
| `rejected-ideas.md` | Dropped ideas and the reasons |
| `cyberbrick-config/`, `cyberbrick-code/` | The receiver's configuration files and the Python snippets that run on it |
| `audio-simulation/` | Rendered engine sounds from the simulations |
