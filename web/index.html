Engine sound sets

Sound sets for the cyberbrick_sound module: see what is on it, try one, change or add a set. Chrome or Edge on a computer, the module on USB.

This app needs Chrome or Edge on a computer.
Not connected.
While the app talks to the module, the engine on the module is silent; it comes back a few seconds after the last action.
How to use (the steps, and what each button does)
  • Connect over USB: choose the module's USB port (Chrome or Edge). "Simulated module" lets you try the app without hardware; nothing is written anywhere. While the app is connected the engine on the module is silent, and the module may speak the name of its start set when the app connects.
  • Test chooses the set on the module, which says its name and plays a demo of about 25 s (starter, engine, gears, horn, stop); no receiver is needed. Stop silences it at once. Test does not change which set the module starts with.
  • Activate makes the set the active one: the module starts with it after power-up (the green "active" mark). The BOOT button on the module steps to the next set and also makes it the active set.
  • Copy is the easy way to a new set: the starter, horn and shift come along and only the engine changes. Edit changes a set in place. New empty set starts from nothing.
  • In the editor, drop a sound on its row or Choose file; Play lets you hear it (loops looped, at any rpm). The Name is the set's spoken number by default; Record, a file or Speak make a spoken name instead.
  • Write to the module writes only what you changed. Delete removes a set after a question; it cannot be undone.

A fuller manual with pictures and what to do when something does not work: docs/user-guide.md in the project.

What a good sample is like (format, file names, lengths, loops)
  • Format on the module: WAV (.wav), PCM, 22 050 Hz, 16 bit, mono, with fixed names: name.wav, start.wav, horn.wav, shift.wav, and for a sample set idle.wav and loaded.wav, plus set.json with the parameters, all in the folder NN_description (NN = the number). This app writes all of that itself: you can drop WAV, MP3, OGG, FLAC or M4A at any rate, stereo or mono, under any name; it is converted and renamed. Best source: WAV or FLAC at 44.1 or 48 kHz (MP3 adds its own noise).
  • Lengths: name 1-2 s, starter 0.5-2 s, horn 1-2 s, shift 0.1-1 s, idle loop 1-6 s, loaded loop 1-3 s. A set takes about 0.2-0.6 MB; the module has room for about 4.6 MB.
  • Loops (idle, loaded, horn) play over and over: steady rpm, no revving, gear change, voice or wind. Cut both ends at the same point of the engine cycle (ideally whole firing cycles), near a zero crossing, without fades, at an even level, so no click or pumping is heard on each lap.
  • Layers by rpm (an alternative to the idle and loaded loops): instead of one loop played up to 3x faster, give 2 to 8 loops of the same engine recorded at different steady speeds, the idle one first, each a loop as described here. The module plays the layer nearest the rpm, only a little faster or slower than it was recorded, and blends neighbours, so the sound stays closer to the recording. Each layer has a ratio: its firing frequency divided by that of the first layer (the app can measure it as a guess; check it with Preview). Choose Engine: layers by rpm in the editor. There is no loaded loop in such a set. It needs a firmware that reports layers=1; an older one skips the set.
  • Idle and low rpm: the module plays the loop up to 3x faster with the throttle, so record the engine idling; a loop recorded at high rpm sounds wrong at both ends.
  • Mid range, not bass: the 40 mm speaker plays nothing useful below about 200 Hz. The firing rhythm and the rasp above that carry the engine; a deep rumble alone sounds like silence.
  • Level: peaks at about -1 dB, no clipping, about as loud as the other sets.
  • Quiet background: noise gets louder and higher with the playback rate.
  • One-shots (starter, shift): no silence at the start, a short fade-out (about 50 ms) at the end.
  • Rights: your own recording or one you may use freely (for example CC0).
